Supported API Endpoints

POST /v1/chat/completions

OpenAI chat completion with multi-turn messages, system prompts, stop sequences, and SSE streaming.

POST /v1/completions

Raw text prompt completion with sampling parameters (temperature, top-p, repetition penalty).

POST /v1/embeddings

Compute 128/768-dimensional L2-normalized dense embedding vectors from single strings or arrays.

GET /v1/models

Returns loaded model descriptors and capabilities in standard OpenAI collection format.

GET /api/tags

Ollama model enumeration endpoint, enabling native integration with Ollama web interfaces.

GET /metrics

Real-time server telemetry: active requests, total prompt tokens, and generated tokens count.

Integration

Client Libraries & Quickstart

# Start the server on port 8080
mlx-serve --port 8080 --model mlx-community/Llama-3.2-3B-Instruct-4bit

# Query chat completions via cURL
curl http://localhost:8080/v1/chat/completions \
  -H "Content-Type: application/json" \
  -d '{
    "model": "mlx-community/Llama-3.2-3B-Instruct-4bit",
    "messages": [{"role": "user", "content": "Explain quantum computing in one sentence."}],
    "stream": true
  }'
